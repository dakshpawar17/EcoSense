# EcoSense — AI Carbon Footprint Analyzer & Sustainability Coach

> **Goal:** Build a polished, production-quality hackathon MVP with clean architecture, excellent UI/UX, robust backend, and AI-powered sustainability insights.

---

## 🌿 Project Overview

**EcoSense** enables users to log their daily lifestyle activities across transit, electricity, dietary habits, and retail shopping, calculate their estimated carbon footprint using standardized emission factors, visualize statistical trends through interactive charts, and receive personalized AI-powered sustainability recommendations generated by **Anthropic Claude API**.

---

## 🏗️ Architecture & Technology Stack

### Frontend
- **Framework:** React 19 + Vite + TypeScript
- **Styling:** Tailwind CSS + Custom Glassmorphism design system
- **Icons & Motion:** Lucide React + Framer Motion
- **Visualizations:** Recharts (Pie, Area, Bar, Circular score rings)
- **Forms & Validation:** React Hook Form + Zod
- **API Client:** Axios

### Backend
- **Runtime:** Node.js + Express.js + TypeScript
- **Database & ORM:** SQLite + Prisma ORM
- **Validation & Security:** Zod + Helmet + CORS
- **AI Integration:** Anthropic Claude API (`claude-3-5-sonnet`) with intelligent rule-based fallback engine

## ✨ Features

1. **Daily Activity Logger:** Log transport (car, bus, train, flight, bike, walk), electricity kWh and source (grid, solar, mixed), diet pattern (meat heavy, mixed, vegetarian, vegan), and shopping purchases. Includes live carbon estimate preview as you type!
2. **Standard Emission Calculation Engine:** Standardized factors (e.g. Car 0.21 kg/km, Bus 0.10 kg/km, Grid 0.45 kg/kWh, Solar 0 kg, Meat Heavy 7.2 kg/day, Shopping 2.5 kg/order).
3. **Dynamic EcoScore Gauge:** 0–100 animated score ring & letter grades (A+, A, B, C, D, F).
4. **Claude AI Sustainability Coach Report:** Returns structured JSON with 4 specific actionable recommendations, potential impact saved in kg CO₂, and national benchmark comparison.
5. **Interactive Recharts Visualizations:** Category Breakdown (Pie), Weekly Emission Trend (Area), National Benchmark Comparison (Bar).
6. **Activity Log History Table:** Search, filter by transport mode, pagination, and one-click **CSV export**.
7. **Badges & Reduction Goals:** Unlock sustainability milestones and track progress towards Net-Zero.

## ⚡ Quick Start / Installation

### Prerequisites
- Node.js (v18+)
- npm

### 1. Install Dependencies
```bash
npm run install:all
```

### 2. Setup Database & Seed 10 Realistic Entries
```bash
cd backend
npm run prisma:push
npm run seed
cd ..
```

### 3. Start Development Mode
```bash
npm run dev
```
- Frontend: http://localhost:3000
- Backend: http://localhost:5000

---

## ⚙️ Environment Variables

Create `.env` inside `backend/`:
```env
DATABASE_URL="file:./ecosense.db"
ANTHROPIC_API_KEY="your_anthropic_api_key_here"
PORT=5000
```

*Note: If `ANTHROPIC_API_KEY` is omitted, EcoSense seamlessly uses its built-in rule-based AI engine, ensuring 100% demo availability.*

## 🔌 API Documentation

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `POST` | `/api/entries` | Log new activity & compute emissions |
| `GET` | `/api/entries` | Get paginated activity history (supports `search`, `transportMode`, `page`, `limit`) |
| `GET` | `/api/entries/:id` | Get single log detail |
| `DELETE` | `/api/entries/:id` | Remove activity log |
| `POST` | `/api/report` | Generate AI report (Claude API / Fallback) |
| `GET` | `/api/summary` | Get aggregated dashboard metrics & weekly trend |
